<h2>📌 About the Project</h2>

<p>
The <strong>CPSTL Medical Center Management System</strong> is a complete digital solution designed to streamline patient handling, medical records, staff workflows, and reporting processes within the CPSTL Medical Center.
</p>

<p>It was built to solve long-existing operational issues such as:</p>

<ul>
  <li>📄 Manual and slow report handling</li>
  <li>❌ Missing or misplaced patient files</li>
  <li>📚 Difficulty tracking historical medical records</li>
  <li>📊 Lack of analytics, charts, and health trend comparisons</li>
  <li>⏳ Time-consuming appointment verification</li>
  <li>📉 No centralized dashboard for health metrics</li>
</ul>

<p>
This upgraded system introduces automation, secure digital storage, analytics, chart visualizations, and efficient medical record workflows.
</p>

<!-- ===================== INSTALLATION ===================== -->

<h2>🚀 Getting Started</h2>
<p>Follow the steps below to run the project locally.</p>

<h3>📦 Prerequisites</h3>

<p>Install the latest Node.js and npm:</p>

<pre>
npm install npm@latest -g
</pre>

<p>Create MySQL database:</p>

<pre>
CREATE DATABASE myapp;
</pre>

<h3>⚙️ Installation</h3>

<p><strong>1. Clone the repository:</strong></p>
<pre>
git clone https://github.com/siluniT/Med_Records_CPSTL.git
cd Med_Records_CPSTL
</pre>

<p><strong>2. Install backend dependencies:</strong></p>
<pre>
cd backend
npm install
</pre>

<p><strong>3. Install frontend dependencies:</strong></p>
<pre>
cd ../frontend
npm install
</pre>

<p><strong>4. Start backend server:</strong></p>
<pre>
cd backend
npm start
</pre>

<p><strong>5. Start frontend development server:</strong></p>
<pre>
cd ../frontend
npm start
</pre>

<!-- ===================== USAGE ===================== -->

<h2>📂 Usage</h2>

<p>The system provides functionalities for both admin staff and users.</p>

<h3>🧑‍💼 Admin Features</h3>
<ul>
  <li>👤 Add, update, and delete patient profiles</li>
  <li>📄 Upload and manage medical reports</li>
  <li>⬇️ Download patient reports</li>
  <li>📚 View complete medical records</li>
  <li>📊 Compare medical metrics (5-record trend chart)</li>
  <li>🚫 Track absent patients by department</li>
</ul>

<h3>🧑‍⚕️ User Features</h3>
<ul>
  <li>📁 View own medical history</li>
  <li>📌 View latest BMI, BP, FBS, and key health metrics</li>
  <li>📈 View medical comparisons and trends</li>
  <li>📄 Access past medical reports</li>
</ul>
